# Shop Panel — پنل فروشگاه + ربات تلگرام

اپ دسکتاپ Electron برای مدیریت محصولات فروشگاه (رومیزی، کاور مبل و …) و ربات تلگرام سفارش‌گیری.
داده‌ها در `userData` ذخیره می‌شوند (JSON + پوشه `images`) — بدون دیتابیس و بدون ماژول native.

## دانلود

ریپو خصوصی است، پس فایل‌ها را با GitHub CLI بگیرید:

```bash
gh release download v1.12.0 -R alisoltanics/shop-panel -D ~/Downloads
sudo dpkg -i ~/Downloads/ShopPanel-1.12.0-linux-amd64.deb   # نصب در منوی اوبونتو
```

از بخش [Releases](https://github.com/alisoltanics/shop-panel/releases):

- **Ubuntu / Debian**: `ShopPanel-1.12.0-linux-amd64.deb` → با دوبار کلیک نصب می‌شود و آیکونش در منوی برنامه‌ها می‌آید.
  یا `ShopPanel-1.12.0-x86_64.AppImage` (بدون نصب: `chmod +x` و اجرا).
- **Windows**: `ShopPanel-Setup-1.12.0.exe` (نسخه ۶۴ بیتی). نسخه ویندوز امضای دیجیتال ندارد؛ ممکن است SmartScreen هشدار بدهد (More info → Run anyway).

## اجرا از سورس

```bash
npm install
npm start
```

### آیکون در منوی اوبونتو (اجرای از سورس)

```bash
npm run install:desktop      # ساخت فایل .desktop و آیکون در ~/.local/share
npm run uninstall:desktop    # حذف از منو
```

سپس «Shop Panel» یا «پنل فروشگاه» را در جستجوی برنامه‌ها پیدا کنید.

## راه‌اندازی ربات (یک بار)

1. در تلگرام به `@BotFather` بروید، `/newbot` بزنید و **توکن** را کپی کنید.
2. از اکانت تلگرام فروشگاه، ربات را باز کنید و `/start` بدهید.
3. دستور `/id` را بفرستید؛ عددی که می‌دهد **چت آیدی فروشگاه** است.
4. در اپ، تب «تنظیمات و ربات»: توکن + چت آیدی را وارد و ذخیره کنید. ربات خودکار روشن می‌شود.

## قابلیت‌ها

### پنل محصولات

- ثبت/ویرایش/حذف محصول با نام، دسته، قیمت پایه، موجودی، جنس، رنگ‌ها، توضیحات، **چند عکس** و **یک ویدیو**
- هر ردیف بُعد شامل **ابعاد**، **تعداد نفرات**، **شکل**، **رنگ (اختیاری)**، **قیمت** و **موجودی** است
- برای دسته «رومیزی» فیلدهای قیمت/موجودی پایه در فرم مخفی می‌شوند و همه‌چیز در ردیف ابعاد ثبت می‌شود
- موجودی محصول در کارت و ربات برابر **جمع موجودی ابعاد** نمایش داده می‌شود
- «تعداد نفرات» و «شکل» از لیست‌های قابل مدیریت در تنظیمات انتخاب می‌شوند؛ افزودن/ویرایش/حذف گزینه‌ها برای همیشه ذخیره می‌شود
- ترکیب‌هایی که در نسخه‌های قبلی با «ویژگی‌ها» ساخته شده بودند، به‌صورت خودکار به ردیف‌های ابعاد تبدیل می‌شوند
- ربات برای هر بُعد یک دکمه می‌سازد، موجودی همان بُعد را نشان می‌دهد و با نهایی شدن سفارش کم می‌کند
- **مدیریت دسته‌بندی‌ها** در تنظیمات؛ انتخاب دسته از لیست هنگام ثبت محصول
- **هزینه ارسال/پست** در تنظیمات؛ به سبد خرید و فاکتور سفارش اضافه می‌شود
- **لیست سفارش‌ها** در تب «سفارش‌ها»: وضعیت، تاریخ، مشتری، اقلام، هزینه ارسال و جمع کل
- **تب مشتریان**: همه خریدارانی که سفارششان نهایی شده، با تعداد خرید، مجموع خرید و **تاریخچه کامل اقلام هر سفارش** (همیشه ذخیره می‌ماند)
- **داشبورد آماری** بالای صفحه محصولات: تعداد محصولات، موجودی کل، سفارش‌های در انتظار و فروش نهایی‌شده
- رابط کاربری تازه با نوار کناری، کارت‌های محصول و صفحه‌بندی عنوان برای هر بخش
- فعال/غیرفعال کردن محصول در ربات + جستجو و فیلتر دسته

### ربات (تلگرام یا بله)

- **تنظیمات کاملاً مستقل برای تلگرام و بله (Bale)**: هر کدام توکن، چت آیدی، یوزرنیم پشتیبانی و وضعیت جداگانه دارند
- هر دو ربات می‌توانند **همزمان** فعال باشند؛ سفارش‌ها در صف ارسال هر پیام‌رسان جدا نگه‌داری می‌شوند
- منوی ثابت (🛍 محصولات / 🧺 سبد خرید / 📖 راهنما) و منوی فرمان‌ها
- کارت محصول با عکس، **ویدیو**، مشخصات و انتخاب مرحله‌ای بُعد و ویژگی‌ها
- سبد خرید با نمایش بُعد و تعداد، حذف آیتم و جمع کل
- **ذخیره اطلاعات مشتری**: در سفارش‌های بعدی اطلاعات قبلی نمایش داده می‌شود تا تأیید یا ویرایش شود (نام، تلفن، کد پستی، آدرس)
- پس از ثبت سفارش: پیام «ارسال شد» + دکمه **«ارسال پیام به فروشگاه برای نهایی کردن سفارش»** که چت پشتیبانی (پیش‌فرض `@MeadowSupport`) را با متن آماده باز می‌کند؛ یوزرنیم در تنظیمات تغییرپذیر است
- **موجودی هرگز به مشتری نمایش داده نمی‌شود** (فقط برای کنترل موجودی فروشگاه استفاده می‌شود)
- عکس‌های محصول به‌صورت **آلبوم** و با یک درخواست ارسال می‌شوند (`sendMediaGroup`)
- شناسه فایل (`file_id`) هر عکس/ویدیو در اپ کش می‌شود؛ ارسال‌های بعدی **بدون آپلود مجدد و فوری** هستند
- اگر پیام‌رسان آلبوم را پشتیبانی نکند، به‌صورت تکی (باز هم با کش) ارسال می‌شود؛ بیش از ۱۰ عکس با دکمه «دیدن عکس‌های بیشتر» می‌آید
- قیمت هر گزینه در توضیحات به‌صورت **لیست کامل** می‌آید و دکمه‌های ابعاد متن کامل دارند (بدون کوتاه‌شدن)
- **لغو سفارش** از تب سفارش‌ها با انتخاب دلیل (ناموجود، انصراف، پرداخت، …) یا متن دلخواه؛ پیام لغو با دلیل برای مشتری ارسال می‌شود
- **کد رهگیری پست** برای هر سفارش؛ با ثبت کد، متن آماده «ارسال شد + کد رهگیری» برای مشتری فرستاده می‌شود
- **تب بازدیدها**: چه کسانی و در چه روزی لیست محصولات را دیده‌اند (هر کاربر در هر روز فقط یک بار ثبت می‌شود)
- سفارش ارسالی به فروشگاه شامل کد سفارش، اطلاعات کامل مشتری (با کد پستی)، بُعد، **گزینه‌های انتخابی**، تعداد، هزینه ارسال و جمع کل + عکس اقلام
- دکمه **«✅ نهایی کردن سفارش»** در چت فروشگاه: کاهش خودکار موجودی و به‌روزرسانی زنده لیست محصولات در اپ
- **صف ارسال**: اگر اینترنت قطع باشد پیام به صف می‌رود، هر دقیقه دوباره تلاش می‌شود و پس از ۲ ساعت حذف می‌شود
- فرمان‌های ربات: `/start`، `/products`، `/cart`، `/help`، `/id`

### زیرساخت

- `.deb` / `.AppImage` برای لینوکس و نصب‌کننده NSIS برای ویندوز
- انتشار خودکار با تگ `v*` از طریق GitHub Actions
- تست دودی رابط کاربری: `npm run test:smoke`
- تست منطق ربات با کلاینت ساختگی (سبد، گزینه‌ها، نهایی‌سازی، صف ارسال): `npm run test:bot`

## بیلد

```bash
npm run dist:linux   # .deb + .AppImage در پوشه release
npm run dist:win     # نصب‌کننده NSIS (ترجیحاً روی ویندوز یا CI)
```

## انتشار نسخه جدید

```bash
npm version patch        # یا minor / major — تگ v می‌سازد
git push --follow-tags
```

با پوش شدن تگ، GitHub Actions (`.github/workflows/release.yml`) روی `ubuntu-latest` و `windows-latest`
بیلد می‌گیرد و فایل‌های `.deb`، `.AppImage` و `Setup.exe` را به‌صورت Release منتشر می‌کند.
